# ASUS Light

ROG 幻 14 GA403WP 的本机灯光控制工具，基于 Node.js + 浏览器页面，不依赖 Electron、.NET SDK 或新增驱动。当前不是 EXE 程序。

## 前置条件

### 设备与系统

| 项目 | 要求 |
| --- | --- |
| 笔记本 | 当前仅适配并实测 ROG 幻 14 GA403WP，控制设备为 `VID 0B05 / PID 19B6`。不是所有华硕笔记本都通用。 |
| 操作系统 | 本机在 Windows 11 x64 上验证；其他 Windows 版本、macOS 和 Linux 尚未验证。双击启动脚本仅供 Windows 使用。 |
| Node.js | 24 或更新版本，自带 npm；本机验证版本为 Node.js `24.22.0`、npm `11.19.1`。 |
| 浏览器 | 新版 Firefox（含 Zen）、Microsoft Edge 或 Google Chrome。 |
| 文件位置 | 保留完整项目文件，放在当前用户可写的目录，以便安装依赖、保存配置；不要只复制网页文件。 |

### 驱动是否需要安装

- **正常情况下不用额外下载灯光驱动。** 程序通过 `node-hid` 调用 Windows 已有的 HID 驱动，设备管理器应能正常识别华硕 HID 设备，不能出现驱动错误或黄色感叹号。
- 本机已安装 `ASUS System Control Interface v3`，但当前实现直接访问 HID，不调用它的 ACPI 接口，**未将它或 Armoury Crate、G-Helper 列为本程序的必装依赖**。无需为了运行本工具额外安装这些控制软件，也不要卸载已有系统驱动来尝试修复灯光。
- 如果设备确实缺失或有驱动错误，先通过 Windows 更新或[华硕官方支持中心](https://www.asus.com/support/Download-Center/)按具体机型检查驱动和固件，再重新检测。不要使用 Zadig 把键盘驱动替换为 WinUSB。

### 系统需要怎么设置

1. Windows 设置 → 个性化 → 动态光效：**建议关闭“在我的设备上使用动态光效”**，避免 Windows 与本工具同时控制灯光。这是防冲突建议，不是已经证实的“不亮原因”；不需要先开启它才能使用本工具。
2. 不要同时让多个软件持续接管灯光。如果 Armoury Crate、G-Helper 等正在运行，先退出其中的灯光控制或同步功能。本机在华硕后台服务仍运行的情况下已完成测试，**不要求先停用全部华硕服务**，程序也不会替你停止它们。
3. 普通方式启动即可，程序不会主动请求管理员权限。若出现“访问被拒绝”，先检查设备状态、控制软件冲突和安全软件拦截，不要直接替换驱动或关闭系统安全功能。
4. 不需要修改 BIOS、开放局域网端口、关闭防火墙，或授权麦克风、屏幕共享。服务只监听本机 `127.0.0.1`。
5. 安装 Node.js 后若提示找不到 `node`，重新打开终端；在 VS Code 内启动时可能需要重启 VS Code，以加载更新后的 PATH。

## 下载与启动

### 获取源码

从 [GitHub 仓库](https://github.com/junhong-l/AUSU-light)选择 **Code → Download ZIP** 并解压，或使用已安装的 Git 下载：

```powershell
git clone https://github.com/junhong-l/AUSU-light.git
cd AUSU-light
```

后续命令均在包含 `package.json` 和 `start.cmd` 的项目目录中执行。下载源码时不包含依赖或个人配置，首次使用需要安装依赖。

### 第一次使用

1. 已安装 Node.js 24 或更新版本则跳过这一步；否则从 [Node.js 官网](https://nodejs.org/zh-cn/download)安装对应 Windows x64 版本并保留 npm、PATH 相关默认选项。**本项目不要求勾选额外的原生模块编译工具安装选项。**
2. 在项目目录打开终端，检查运行环境：

	```powershell
	node --version
	npm.cmd --version
	```

3. 安装锁文件指定的项目依赖：

	```powershell
	npm.cmd ci
	```

	此步骤通常需要联网下载到项目的 `node_modules` 目录，不是安装系统驱动。直接依赖为 `node-hid`（硬件访问）和 `lucide`（本地图标），npm 还会安装它们需要的间接依赖。

4. 双击 [start.cmd](start.cmd)，或在项目目录执行：

	```powershell
	npm.cmd start
	```

	浏览器会自动打开本地控制页面。如果没有自动打开，手动访问启动窗口显示的地址。**不能直接双击 HTML 文件代替启动服务。**

### 后续启动

Node.js 和依赖已经安装后，直接双击 [start.cmd](start.cmd) 即可，**不必每次重新下载，也不需要联网**；页面图标等资源均从本地加载。

默认地址为 `http://127.0.0.1:3210`，端口被占用时依次尝试后面 9 个端口，以控制台显示的地址为准。保留启动窗口，使用完成后按 `Ctrl+C` 停止服务。关闭网页不会停止服务；常规灯效在服务退出后保留。

如果启动窗口提示缺少依赖，请回到项目目录执行 `npm.cmd ci` 再启动；双击脚本只负责检查和启动，**不会自动安装依赖**。删除了 `node_modules`、换了电脑或更新了锁文件时，也需要重新安装。

### 不需要安装的组件

当前已验证的运行方式不需要 Electron、.NET SDK、Python、Visual Studio C++ 编译工具、新增 HID 驱动或虚拟音频驱动。Windows x64 的 `node-hid` 预编译模块已在本机验证可用；**如果其他环境的依赖安装转而要求编译器或额外组件，请先停止并核实原因，不要盲目安装。**

## 功能

- 键盘：独立开关、RGB 颜色、常亮/呼吸/色彩循环/闪烁、三级亮度和动画速度。
- 常用颜色：点击加号打开添加窗口，选色或输入 HEX 色值后确认添加；重复颜色不重复收藏，取消不改动列表。选中色块后点击减号删除；保留 1 至 24 个，删除后自动选中相邻色块，可连续删除，最后一个不能删除。循环模式下也可管理常用颜色。列表保存在当前浏览器的本地存储中，同一地址刷新后保留；更换浏览器、端口或清除网站数据不会保留这份列表。增删不写硬件。
- 键盘预览随灯效和速度变化；浏览器启用“减少动态效果”时，预览不播放动画，不影响设备的灯效命令。
- A 面 Slash Lighting：独立开关、白光、常亮及六种预设动画、三级亮度和动画间隔。
- 两区分别点击“应用”提交，未应用的界面改动不会写入硬件。
- 成功发送后将选择保存到本地 `data/settings.json`；再次启动只载入选择，**不会自动应用**。
- 设备诊断与本次会话的最近 20 条操作记录。记录中的“已发送”表示协议操作完成，不等同于传感器确认灯光亮起。

当前只适配经本机核实的 `VID 0B05 / PID 19B6`，不是通用华硕设备控制器。不修改风扇、功耗、驱动、服务、电池灯光策略、合盖策略、开机或睡眠动画。A 面按设备协议提交设置，可能保留到程序退出以后。

呼吸、色彩循环、闪烁和 A 面预设动画不是音乐同步。本版本不提供音频检测或音乐律动。

## 不亮或设置被覆盖

1. Windows 设置 → 个性化 → 动态光效，建议关闭 Windows 的接管，避免多个控制器争抢。
2. 点击刷新，检查键盘和 A 面接口是否识别；刷新不会更改灯光。
3. 开启对应开关，选择常亮和非黑色键盘颜色，再点击对应的应用按钮。
4. 如果命令报错或超时，可能已经部分生效。先观察设备，再重试，不要连续反复提交。
5. 华硕后台程序可能覆盖灯效。本工具不会自动停止它们；不要直接卸载系统控制接口驱动。
6. 睡眠唤醒或其他软件接管后，可以重新点击应用。本版本不安装后台常驻服务，也不自动追踪系统电源事件。

## 安全与实现

服务仅绑定 `127.0.0.1`，校验 Host、Origin 和每次启动生成的控制令牌，不启用跨域访问。所有硬件命令在同一队列内串行执行，只打开已验证的供应商专用接口，不访问键盘输入或固件更新接口。

键盘使用 `0x5A` / 63 字节亮度 Feature 报告和 `0x5D` / 128 字节 Aura 输出报告；A 面使用 `0x5D` / 128 字节 Feature 报告，先查询并保留其余模式槽位，再提交选中模式。收到不认识的响应时停止应用。

协议核对来源：[G-Helper AsusHid](https://github.com/seerge/g-helper/blob/main/app/USB/AsusHid.cs)、[Aura](https://github.com/seerge/g-helper/blob/main/app/USB/Aura.cs)、[SlashDevice](https://github.com/seerge/g-helper/blob/main/app/AnimeMatrix/SlashDevice.cs)。基础亮度、键盘变色和 A 面常亮已由本机人工观察确认；其他预设模式需逐项实测，不承诺所有固件表现相同。
